# Определение времени года по дате

Веб-приложение на HTML + CSS + JavaScript для определения времени года по введённой дате.

## Возможности
- Ввод дня, месяца и (опционально) года
- Проверка корректности даты, включая 29 февраля
- Мгновенное определение сезона (метеорологический подход, Северное полушарие)
- Наглядный результат: зелёный блок при успехе, красный — при ошибке

## Установка
1. Скачать файл `index.html`.
2. Открыть его в любом современном браузере.
